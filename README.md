## Sobre mí

Estudiante de **Ingeniería en Desarrollo y Gestión de Software** en la **Universidad Tecnológica del Valle de Toluca (UTVT)** y TSU en Desarrollo de Software Multiplataforma.

Construyo soluciones completas, desde la base de datos y la API hasta la interfaz web o móvil, con interés en infraestructura cloud y automatización. Mi objetivo es incorporarme al sector gobierno o bancario como desarrollador de software.

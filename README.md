## Perfil profesional

Estudiante de Ingeniería en Desarrollo y Gestión de Software con experiencia en el desarrollo de aplicaciones web y móviles, diseño de bases de datos y automatización de infraestructura en la nube. Orientado a la construcción de sistemas confiables, mantenibles y seguros, con interés en incorporarme al sector gubernamental o bancario.

## 👨‍💻 Sobre mí

Soy estudiante de **Ingeniería en Desarrollo y Gestión de Software** en la **Universidad Tecnológica del Valle de Toluca (UTVT)**, TSU en Desarrollo de Software Multiplataforma. Me enfoco en construir soluciones completas: desde la base de datos y la API hasta la interfaz web o móvil.

- 🏥 Desarrollo un **sistema de gestión hospitalaria** en PHP como proyecto real para un cliente del sector salud.
- 📱 Creo apps móviles con **Kotlin / Jetpack Compose**, incluida una app para **Wear OS**.
- ☁️ Practico **infraestructura como código** con Terraform en Azure.
- 🎯 Objetivo: integrarme al sector **gobierno o bancario** como desarrollador de software.
